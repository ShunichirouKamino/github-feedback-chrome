# セキュリティ対策一覧（v0.2.0）

github-feedback が想定する脅威と対策の一覧です。各対策から実装箇所に飛べます。
実装へのリンクは [`17ea596`](https://github.com/ShunichirouKamino/github-feedback-chrome/tree/17ea5964ace4c4e8a08feee4c9abe0b0c2897266) に固定したパーマリンクなので、以降のコード変更で行がずれることはありません（対策のコードを変えたら、この資料も更新してください）。

## 前提

| 項目 | 内容 |
|---|---|
| 守るもの | 社内画面の内容（URL・DOM・ログ・スクリーンショット）、起票先リポジトリ、利用者の GitHub セッション |
| 信用しないもの | 対象ページ（拡張機能と DOM を共有し、MAIN world のスクリプトは改ざんできる）、ページから取得した全データ、設定画面への入力値 |
| 信用するもの | 拡張機能の隔離ワールド・service worker、設定した GitHub のホスト |
| 方針 | 判断と検証は service worker 側で行う。ページ由来の値は無害化してから使う。最小権限。Submit は必ず人が行う |

## 受け入れたリスク

| リスク | 受け入れた理由 | 利用者への周知 |
|---|---|---|
| マスクは推定ベースで完全ではない。スクリーンショットの写り込みは伏せられない | 自由形式のデータを完全に判定する方法がない。Submit 前に人が GitHub の画面で確認する運用を前提にする | README、設定画面のスクショ範囲の注記 |
| スクショは貼り付けた時点で GitHub にアップロードされる（Submit しなくても残る） | GitHub の通常の画像添付と同じ挙動。起票先は 1・3・9 の対策で正しいことを保証する | README |
| ページは自分の診断データを読める・偽装できる | 記録しているのはそのページ自身のログと通信で、ページは元から任意の文字列を `console.error` に出せる。本文では「未検証データ」として隔離する | 本文の注記 |
| ページは拡張機能の UI を消して使えなくできる | 可用性の問題で情報は漏れない | — |
| タイトルは URL に載る | 利用者自身が書いて公開する前提の文字列 | — |
