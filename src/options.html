github-feedback 設定

基本

GitHub サーバーの URL です。github.com（Enterprise Cloud を含む）なら https://github.com のままにしてください。 自社サーバーで動かす GitHub Enterprise Server を使う場合だけ、https://ghe.example.co.jp のように変更します。

下の「ホストごとの振り分け」のどれにも一致しなかったときに起票するリポジトリです。 owner/repo の形式か、リポジトリの URL をそのまま貼り付けてください。振り分けルールだけで足りるなら空欄で構いません。

デフォルトの起票先に起票するときに付けるラベルです（カンマ区切り）。 リポジトリに存在しないラベルや、Triage 以上の権限がない場合は付きません。

ホストごとの振り分け

開いている画面のホスト名（ポート付き）を上から順に照合し、最初に一致したルールの起票先を使います。

ホストのパターン起票先リポジトリ環境名ラベル

ホストのパターン
対象の画面のホスト名です。* はワイルドカードです。 例: localhost:*（どのポートでも）/ *.stg.example.com / d1234abcd.cloudfront.net
起票先リポジトリ
一致したときに起票するリポジトリです。owner/repo の形式か、URL をそのまま貼り付けてください。
環境名
Issue のタイトル先頭（例: [stg] ボタンが押せない）と、本文の「環境」欄に入ります。 空欄の場合、localhost なら local、それ以外は付きません。
ラベル
Issue に付けるラベルです（カンマ区切り。例: feedback,env:stg）。 空欄ならデフォルトのラベルを使います。Triage 以上の権限がない場合は付きません。
